### 视频引擎调研

```
CreatePeerConnectionFactory(
    rtc::Thread* network_thread,
    rtc::Thread* worker_thread,
    rtc::Thread* signaling_thread,
    rtc::scoped_refptr<AudioDeviceModule> default_adm,
    rtc::scoped_refptr<AudioEncoderFactory> audio_encoder_factory,
    rtc::scoped_refptr<AudioDecoderFactory> audio_decoder_factory,
    std::unique_ptr<VideoEncoderFactory> video_encoder_factory,
    std::unique_ptr<VideoDecoderFactory> video_decoder_factory,
    rtc::scoped_refptr<AudioMixer> audio_mixer,
    rtc::scoped_refptr<AudioProcessing> audio_processing,
    std::unique_ptr<AudioFrameProcessor> audio_frame_processor = nullptr,
    std::unique_ptr<FieldTrialsView> field_trials = nullptr);

}  // namespace webrtc
```

- 创建PeerConnectionFactory的参数中，与视频引擎相关的是 std::unique_ptr<VideoEncoderFactory> video_encoder_factory 和 std::unique_ptr<VideoDecoderFactory> video_decoder_factory
- 可以通过重写VideoEncoderFactory、VideoDecoderFactory、Decoder、Encoder，创建PeerConnectionFactory时传入不同重写的视频编解码工厂
- 可以通过PeerConnection的指针得到rtc::scoped_refptr<webrtc::RtpSenderInterface> sender，通过sender修改编解码器的帧率、码率、分辨率等参数
- 可以通过视频轨道video_track_设置是否发送black frames开关摄像头
