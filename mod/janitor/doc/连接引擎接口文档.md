##  连接引擎接口文档

#### 初始化接口

- Janitor(std::string ip, v_uint16 port)：与 janus 服务器连接
- void init（）：创建janus会话和NoSIP插件句柄，开启 keepAlive 循环   
- void registerObserver(JanitorObserver* callback)：用于回调函数重写后的实现
- void OnReconnect():连接引擎检测到断网后，自行重连，重新连上janus后会调用该接口

#### NoSIP接口

- void generateSDP(std::string jsepSdp, std::string type)：发送JSEP SDP，设置Type，并发送到 janus

  - 回调OnGrenerated（std::string& normalSdp ，std::string& normalType）：janus 回复 grenerated 时调用，并返回 normal


- void processSDP(std::string normalSdp, std::string type)：发送normal SDP，设置Type，并发送到 janus

  - 回调OnProcessed（std::string& jsepSdp，std::string& jsepType）：janus 回复 processed 时调用，并返回 JSEP jsep


#### 与janus交互接口 

- void addNoSIP()：注册新的NoSIP插件，用于结束通话后，开启新通话时重新协商PC

- void sendTrickleToJanus(const std::string& ice)：发送本地ICE候选人

- void sendTrickleCompleteToJanus()：结束ICE发送
