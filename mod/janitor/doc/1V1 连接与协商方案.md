## 基于Janus NoSIP的直接 1v1 通话 连接与协商方案 设计输出

#### 依赖库
- oatpp
- webrtc

#### 1.初始化与Janus服务器的会话

- 创建websocket客户端，与janus服务器连接
    - 创建 listener对象，监听回复信息

- 客户端发送一个包含`"janus": "create"`的JSON请求来创建与Janus的会话

- 成功创建会话后，Janus服务器会返回一个包含会话ID的响应。

```cpp
std::string create_session_message = R"({
    "janus": "create",
    "transaction": "create_session_trx"
})";
send_message(create_session_message);
```

- create_session_trx 是一个由客户端生成的唯一标识符，用于匹配请求和响应。

#### 2. 接收响应并提取 session_id

Janus服务器在接收到创建会话请求后，会返回一个响应

- 其中包含`"janus": "success"`和`"data"`字段
  - "data" 字段中包含 "id" 字段，这个字段就是分配给新会话的`session_id`。

```json
{
    "janus": "success",
    "transaction": "<transaction_id>",
    "data": {
        "id": <session_id>
    }
}
```

- <transaction_id>值为create_session_trx ，用于确保请求的隔离性、一致性、原子性和持久性
- 每个请求都应该有一个唯一的`transaction_id`，以区分不同的请求。

#### 3.附加到NoSIP插件

发送一个包含`"janus": "attach"`和`"plugin": "janus.plugin.nospip"`的JSON请求来完成的。

- 成功附加后，Janus服务器会返回一个包含插件句柄的响应。

```cpp
std::string attach_plugin_message = R"({
    "janus": "attach",
    "plugin": "janus.plugin.nospip",
    "session_id": session_id,
    "transaction": "attach_plugin_trx"
})";
send_message(attach_plugin_message);
```

#### 4.主叫caller 发送`generate`请求

使用插件句柄来发送`generate`请求

- 将JSEP提供的SDP转换为NoSIP插件可以处理的精简SDP
    - 用webrtc创建本地sdp（jsep格式）
- 收到 generated 回复表示转换成功

```cpp
std::string generate_message = R"({
    "janus": "message",
    "body": {
        "request": "generate",
        "srtp": "sdes_optional"
    },
    "session_id": session_id,
    "handle_id": plugin_handle,
    "transaction": "generate_trx"
})";
send_message(generate_message);
```

#### 5.通过信令与被叫callee 交互

1）主叫caller 调用信令 forward（）将转换后的caller.SDP 传给被叫callee

-  callee 收到 caller.SDP 后
 - 1.创建与janus的会话
 - 2.将会话附加到NoSIP插件
 - 3.向janus 发送generate 请求，将JSEP提供的SDP转换为NoSIP插件可以处理的精简SDP
 - 4.收到 generated 回复表示转换成功，得到callee.SDP
 - 5.向janus 发送process 请求，将caller.SDP  转化成 JSEP格式的SDP

2）被叫callee 调用信令 forward（）将转换后的callee.SDP 传给主叫caller


#### 5.发送process请求

使用插件句柄来发送`process`请求

- 收到信令传来的callee.SDP
- 将callee 的精简SDP转换为JSEP格式的SDP
- 收到 processed 回复表示转换成功

```cpp
std::string process_message = R"({
    "janus": "message",
    "body": {
        "request": "process",
        "type": "offer", // 或 "answer"，取决于你处理的是哪种类型的SDP
        "sdp": "your_stripped_sdp_here"
    },
    "session_id": session_id,
    "handle_id": plugin_handle,
    "transaction": "process_trx"
})";
send_message(process_message);
```
