# 连接引擎2.0 API

- namesapce: rtcengine
- 视频引擎: Y组
- 音频引擎: J组

### bool connect(std::string signalIp, uint16_t signalPort)

```
- signalIp: 信令服务器IP
- signalPort: 信令服务器Port
```

- 用户开启连接信令服务器

- 返回值: true: 成功 / false: 失败

### bool login(string userId, string password)

```
- userId: 用户名
- password: 登录密码
```

- 用户登录

- 返回值: true: 成功 / false: 失败

### bool logout()

- 用户登出 (仅考虑切换账号情况)

- 返回值: true: 成功 / false: 失败


### bool relogin()

- 用户重新登录 (断网后重连)

  - 会议期间重连
  - 非会议期间重连
- 返回值: true: 成功 / false: 失败

### bool scheduleMeeting(videoMcu videoMcu, AudioMcu audioMcu, VideoCodecType videoType, AudioCodecType audioType)

```
- videoMcu: 选择使用的视频mcu(Y/J)
- audioMcu: 选择使用的音频mcu(X/L)
- videoType: 选择视频编解码格式(H264/VP9)
- audioType: 选择音频编解码格式(PCMA/OPUS)
```

- 预定会议
- 返回值: true: 成功 / false: 失败

### bool createMeeting(VideoMcu videoMcu, AudioMcu audioMcu, VideoCodecType videoType, AudioCodecType audioType)

  ```
- videoMcu: 选择使用的视频mcu(Y/J)
- audioMcu: 选择使用的音频mcu(X/L)
- videoType: 选择视频编解码格式(H264/VP9)
- audioType: 选择音频编解码格式(PCMA/OPUS)
  ```

- 创建会议
- 返回值: true: 成功 / false: 失败

### bool joinMeeting(string meetingId)

  ```
- meetingId: 会议号
  ```

- 加入会议
- 返回值: true: 成功 / false: 失败

### bool exitMeeting()

- 退出会议
- 返回值: true: 成功 / false: 失败

### void closeMeeting()

- 结束会议

### void setCamera(int devId)

```
- devId: 摄像头设备Id
```

- 选择摄像头

### bool openCamera()

- 开启摄像头
- 返回值: true: 成功 / false: 失败

### bool closeCamera()

- 关闭摄像头
- 返回值: true: 成功 / false: 失败

### bool openMicphone()

- 返回值: true: 成功 / false: 失败

### bool closeMicphone()

- 返回值: true: 成功 / false: 失败

### bool closeScreenShare()

### int switchLayout(string layoutNum)

```
- layoutNum: 布局编号
```

- 切换会议画面布局
- 返回值: true: 成功 / false: 失败

### void getMediaInfo(MediaInfo &mediaInfo);

- 获取当前媒体信息

```
- MediaInfo:媒体信息结构体
  - inFrameRate：输入帧率
  - outFrameRate：输出帧率
  - inBitrate：输入带宽
  - outBitrate：输出带宽
```

### void outbound(string targetUserId)

- 外呼用户加入会议

```
- targetUserId: 目标用户id
```



## 回调接口


### virtual void OnReconnectSuccess() = 0;

- 告知 与信令服务器重连成功

### virtual void OnReconnectFailure() = 0;

- 告知 与信令服务器重连失败

### virtual void OnLoginSuccess(std::string userId) = 0;

- 告知 登录成功

### virtual void OnLoginFailure() = 0;

- 告知 登录失败

### virtual void OnReceiveTrack(rtc::scoped_refptr<webrtc::RtpReceiverInterface> receiver) = 0; 

```
- receiver: 远端视频画面接收器, 透传
```

- OnAddTrack()中调用

### virtual void OnJoinMeetingFailure() = 0;

- 告知 加入会议失败

### virtual void OnVideoInputDevInfo(std::map<int16_t, std::string> list) = 0;

```
- list: 视频设备列表
```

- 告知 所有摄像头信息

### virtual void OnAudioInputDevInfo(std::map<int16_t, std::string> list) = 0;

```
- list: 麦克风设备列表
```

- 告知 所有麦克风信息

### virtual void OnAudioOutputDevInfo(std::map<int16_t, std::string> list) = 0;

```
- list: 扬声器设备列表
```

- 告知 所有扬声器信息

### virtual void OnScreenInfo(std::map<int16_t, std::string> list) = 0;

```
- list: 屏幕设备列表
```

- 告知 所有屏幕信息

### virtual void OnWindowInfo(std::map<int16_t, std::string> list) = 0;

```
- list: 可共享窗口列表
```

- 告知 所有窗口信息

### virtual void OnScheduleMeeting(std::string&meetingId) = 0;

- 告知预定会议成功

### virtual void OnScheduleMeetingFailure() = 0;

- 告知预定会议失败

### virtual void OnCloseMeeting() = 0;

- 告知会议已结束
